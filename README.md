# Analisis_tienda

Este proyecto tiene como objetivo ayudar al Sr. Juan a decidir qué tienda de su cadena Alura Store es la menos eficiente y recomendar una estrategia basada en datos. Para ello, se analizan métricas clave como ingresos, categorías más vendidas, reseñas de clientes, productos más vendidos y tiempos de envío promedio.

- **Descripción del Proyecto**

Durante el análisis, se trabajó con datos de ventas, rendimiento y reseñas de las cuatro tiendas de Alura Store. Se realizaron las siguientes tareas:

Carga y manipulación de datos: Utilizando la biblioteca Pandas para procesar archivos CSV.

Visualización de datos: Creación de gráficos con Matplotlib para presentar los resultados.

Análisis de métricas clave: Evaluación de ingresos, productos más vendidos y eficiencia en tiempos de envío.

Recomendación final: Propuesta basada en el análisis realizado.

- **Tecnologías Utilizadas**

Python: Lenguaje principal para el análisis.

Pandas: Manipulación y análisis de datos.

Matplotlib: Creación de gráficos para visualización.

Jupyter Notebook (opcional): Para desarrollo interactivo.


- **Resultados Obtenidos**

Se generaron tres tipos principales de gráficos:

Gráfico de barras: Comparación de ingresos por tienda.

Gráfico circular (pie chart): Distribución de categorías más vendidas.

Gráfico de dispersión: Relación entre reseñas y rendimiento.
